# Learning notes

An inventory identifier is a local label, not a universal artifact identity. Matching hash text is a matching declaration; no bytes or publisher were verified. Missing hashes agree only about absence. Different hashes under same labels can describe different artifacts.

Graph consistency asks whether supplied references resolve. Reachability asks which supplied nodes are connected to supplied roots. Neither discovers omitted inventory. A cycle is a valid directed graph property, while a cycle in an API container is malformed admission data.

Freeze error priority and examples before implementation: unknown profiles must not hide malformed common records. Duplicates must preserve every occurrence before optional mathematical deduplication.

Output intent is a correctness boundary: an explicitly supplied empty output path is a file error, not a missing option. Returning success through a fallback channel would conceal failed delivery. A partial write can leave bytes, so exit status matters.

Mutation evidence must identify actual assertion failures. Disabling a whole reference branch initially caused graph lookup errors; refining the deliberate defect to omit the finding while retaining graph gates established the intended behavioral regression. Pure checks and normal/optimized unittest do not depend on removable assert statements.

All 512 three-node directed graphs can be checked against a different boolean transitive-closure oracle. That exhausts those small graphs only, not arbitrary real software dependencies or inventory truth.
